This project features a drop minigame where the user has to collect circles that drop from the top of the screen using buttons. The buttons
control a paddle that catches the circle, and the user has 30 seconds to catch as many as they can.

Parts used:
- ESP32 Dev Module Microcontroller 
- 1.3 inch OLED screen 
- 6x6x5 mm Tactile Push Buttons (2)
- Male to Female Jumper wires (6)
- Breadboard
